## Атрибуты системы программного обеспечения

### Надежность

* **Attributes.Reliability.ErrorHandling**:
    Система должна обрабатывать 99% возникающих ошибок так, чтобы они не приводили к отказу системы или потере данных. Если ошибка приводит к отказу системы, информацию об этом необходимо залогировать.
    <end>

* **Attributes.Reliability.InformationLogging**:
    Система должна логировать информацию о действиях пользователя, ответах системы на них и ошибках, произошедших в системе.
    <end>

* **Attributes.Reliability.DatabaseBackup**:
    База данных должна иметь резервную копию, которая будет использована для восстановления основной базы данных в случае полной или частичной утери данных.
    <end>

### Доступность

* **Attributes.Availability.Uptime**:
    Сервис должен быть доступен пользователям минимум 99% времени в месяц.
    <end>

* **Attributes.Availability.Recover**:
    В случае ошибки, приводящей к отказу системы, должна выполняться автоматическая перезагрузка системы.
    <end>

* **Attributes.Reliability.SystemBackup**:
    Должна иметься возможность отката системы до предыдущей версии в production окружении. Это необходимо в случаях обнаружения ошибок, препятствующих корректной работе системы, после обновлении её версии.
    <end>

### Безопасность

* **Attributes.Security.PasswordEncryption**:
    Пароли пользователей должны храниться в зашифрованном виде.
    <end>

* **Attributes.Security.CrossSiteScripting**:
    Для предотвращения межсайтового скриптинга символы в тексте, введенном пользователем, должны экранироваться перед использованием этого текста в шаблонах компонентов Vue.js.
    <end>

* **Attributes.Security.SqlInjection**:
    Для предотвращения SQL-инъекций необходимо использовать подготовленные SQL-выражения для запросов к базе данных.
    <end>

* **Attributes.Security.DataValidation**:
    Любые данные, введенные пользователем, должны валидироваться перед записью в базу данных.
    <end>

* **Attributes.Security.ErrorDisplay**:
    Пользователь не должен видеть внутренних сообщений об ошибках. Все сообщения об ошибках, которые отображаются для пользователя, должны иметь заранее определенный текст, не содержащий информации о внутреннем устройстве системы.
    <end>

* **Attributes.Security.PasswordLength**:
    Пароль пользователя должен состоять минимум из 8 символов.
    <end>

### Удобство сопровождения

* **Attributes.Maintainability.Documentation**:
    Исходный код должен сопровождаться документацией.
    <end>

* **Attributes.Maintainability.GoCodeStyle**:
    Исходный код на языке go должен быть отформатирован с помощью утилиты `gofmt` и оформлен в соответствии с документом Effective Go [4]. 
    <end>

* **Attributes.Maintainability.VueCodeStyle**:
    Исходный код Vue.js должен быть оформлен в соответствии с официальным руководством по стилю Vue.js [5].
    <end> 

* **Attributes.Maintainability.MSA**:
    Сервисы должны слабо зависеть друг от друга. Это значит, что обновление одного из сервисов не должно влиять на другие сервисы (если изменения не касаются API сервиса).
    <end>

### Мобильность

* **Attributes.Portability.OS**:
    Система должна работать на любом дистрибутиве Linux семейства Debian.
    <end>
