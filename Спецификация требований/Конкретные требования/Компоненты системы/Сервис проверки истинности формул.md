### Сервис проверки истинности формул

#### Назначение компонента

Сервис предназначен для проверки истинности формул одного из логических исчислений:
* пропозициональное $P_1$;
* пропозициональное $P_2$;
* секвенций $LK$;
* функциональное $F_1$;
* функциональное $F_2$;
* интуиционистское пропозициональное $P_I$;
* модальное пропозициональное;

Действующие лица: администратор, преподаватель, студент.

#### Действия пользователя и реакции системы на них

*Действие*: Пользователь выбирает логическое исчисление, вводит корректную в контексте выбранного исчисления формулу.
*Реакция*: Сервис отображает формулу в Latex и выводит результат проверки истинности формулы.

*Действие*: Пользователь выбирает логическое исчисление, вводит некорректную в контексте выбранного исчисления формулу.
*Реакция*: Сервис выводит на экран уведомление об ошибке.

#### Ассоциированные функциональные требования
* **Component.Checker.MaintainedLogic.P1**: 
    Сервис должен предоставлять любому авторизованному пользователю возможность проверить истинность формулы пропозиционального исчисления $P_1$.
    <end>
* **Component.Checker.MaintainedLogic.P2**:
    Сервис должен предоставлять любому авторизованному пользователю возможность проверить истинность формулы пропозиционального исчисления $P_2$.
    <end>
* **Component.Checker.MaintainedLogic.F1**:
    Сервис должен предоставлять любому авторизованному пользователю возможность проверить истинность формулы функционального исчисления $F_1$.
    <end>
* **Component.Checker.MaintainedLogic.F2**:
    Сервис должен предоставлять любому авторизованному пользователю возможность проверить истинность формулы функционального исчисления $F_2$.
    <end>
* **Component.Checker.MaintainedLogic.Sequences**:
    Сервис должен предоставлять любому авторизованному пользователю возможность проверить истинность формулы исчисления секвенций $LK$.
    <end>
* **Component.Checker.MaintainedLogic.PI**:
    Сервис должен предоставлять любому авторизованному пользователю возможность проверить истинность формулы интуиционистского пропозиционального исчисления $P_I$.
    <end>
* **Component.Checker.MaintainedLogic.Modal**:
    Сервис должен предоставлять любому авторизованному пользователю возможность проверить истинность формулы модального пропозиционального исчисления.
    <end>
* **Component.Checker.MaintainedLogic.FormulaFormat**:
    Сервис должен проверять истинность формул, написанных на языке Logical Formulas.
    <end>
* **Component.Checker.LatexRendering**:
    Сервис должен рендерить введенную пользователем формулу в Latex и выводить результат рендеринга на экран.
    <end>
* **Component.Checker.OutputResult**:
    Сервис должен выводить на экран результат проверки формулы в виде текстовой строки со значениями *Истина* и *Не истина*.
    <end>
* **Component.Checker.ErrorDisplay**:
    Если была введена некорректная в контексте выбранного исчисления формула, то сервис должен вывести сообщение об ошибке.
    <end>
