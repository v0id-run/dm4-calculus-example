### Личный кабинет

#### Назначение компонента

Данный сервис предназначен для предоставления каждому виду пользователей необходимую информацию в системе.

Действующие лица: администратор, преподаватель, студент.

#### Действия пользователя и реакции системы на них

Действие: Преподаватель входит в свой личный кабинет.

Реакция: Сервис предоставляет список одной учебной группы, которая проходит курс в данный момент, с оценками каждого из студентов.

Действие: Студент входит в свой личный кабинет.

Реакция: Сервис предоставляет информацию только по контрольным и домашним работам студента, выставленные преподавателем оценки.

Действие: Администратор входит в свой личный кабинет.

Реакция: Сервис предоставляет возможность выполнять SQL-запросы к базе данных, просматривать логи системы.

#### Ассоциированные функциональные требования

* **Component.Account.Authorization**: 
    Для доступа к личному кабинету пользователь должен авторизоваться в системе.
    <end>
* **Component.Account.AccessControl**: 
    Сервис должен разграничивать доступ в зависимости от роли пользователя.
    <end>
* **Component.Account.TeacherPersonalSpace**: 
    Сервис должен предоставлять преподавателю возможность посмотреть таблицу по одной учебной группе с ФИО студентов, их оценками, планы контрольных работ и домашних заданий.
    <end>
* **Component.Account.GroupDisplayFormat**: 
    На странице преподавателя должны быть представлены результаты только по одной группе с возможностью выбора учебной группы.
    <end>
* **Component.Account.StudentPersonalSpace**: 
    Сервис должен предоставлять студенту возможность посмотреть таблицу со своими контрольными и домашними работами и полученными оценками.
    <end>
* **Component.Account.StudentsWorks**: 
    Сервис должен предоставлять студенту возможность перейти на страницу его домашней или контрольной работы.
    <end>
* **Component.Account.AdminPersonalSpace**: 
    Сервис должен предоставлять администратору возможность просматривать логи системы и выполнять SQL-запросы к базе данных.
    <end>
* **Component.Account.ErrorDisplay**: 
    Уведомления о системных ошибках должны отображаться в правом верхнем углу.
    <end>
