### Сервис поддержки вывода формул

#### Назначение компонента

Данный сервис предназначен для автоматизации процесса вывода формул, следующих исчислений:
* пропозициональное $P_1$
* пропозициональное $P_2$
* функциональное $F_1$
* интуиционистское пропозициональное $P_I$;

Действующие лица: администратор, преподаватель, студент.

#### Действия пользователя и реакции системы на них

*Действие*: Пользователь задает контекст ввода, формулу и её обоснование.

*Реакция*: Если обоснование корректно, то сервис предоставляет возможность ввести следующий шаг вывода. Если обоснование некорректно, сервис выводит ошибку.

*Действие*: Пользователь задает контекст ввода и обоснование.

*Реакция*: Если обоснование корректно, то сервис выводит его результат. Если обоснование некорректно, сервис выводит ошибку.

#### Ассоциированные функциональные требования

- **Component.Inference.Authorization**:
    Для доступа к сервису поддержки вывода формул пользователь должен авторизоваться в системе.
    <end>
- **Component.Inference.FormulaFormat**:
    Сервис должен производить поддержку вывода формул и записи обоснований, записанных на языке Logical Formulas.
    <end>
- **Component.Inference.MaintainedLogic.P1**:
    Сервис должен предоставлять любому авторизованному пользователю возможность вывести формулу пропозиционального исчисления $P_1$.
    <end>
- **Component.Inference.MaintainedLogic.P2**:
    Сервис должен предоставлять любому авторизованному пользователю возможность вывести формулу пропозиционального исчисления $P_2$.
    <end>
- **Component.Inference.MaintainedLogic.F1**:
    Сервис должен предоставлять любому авторизованному пользователю возможность вывести формулу функционального исчисления $F_1$.
    <end>
- **Component.Inference.MaintainedLogic.PI**:
    Сервис должен предоставлять любому авторизованному пользователю возможность вывести формулу интуиционистского пропозиционального исчисления $P_I$.
    <end>
- **Component.Inference.Calculus**:
    Сервис должен предоставлять пользователю возможность задать исчисление.
    <end>
- **Component.Inference.Statements**:
    Сервис должен предоставлять пользователю возможность задать утверждения, которые будут использоваться в выводе формулы.
    <end>
- **Component.Inference.FormulaNames**:
    Сервис должен автоматически задавать имена формулам в контексте, данные имена могут использоваться в дальнейшем выводе.
    <end>
- **Component.Inference.VariablesChanging**:
    Сервис должен предоставлять пользователю возможность задать замену переменных в качестве обоснования.
    <end>
- **Component.Inference.ModusPonens**:
    Сервис должен предоставлять пользователю возможность задать правило вывода modus ponens в качестве обоснования.
    <end>
- **Component.Inference.NameAsStatement**:
    Сервис должен предоставлять пользователю возможность задать имя формулы в контексте в качестве обоснования.
    <end>
- **Component.Inference.JustificationResult**:
    Если пользователь задал корректное обоснование, но не задал результат обоснования, сервис должен его вычислять и выводить результат на экран.
    <end>
- **Component.Inference.ErrorNotification**:
    Если введены некорректные данные, сервис должен выводить сообщение об ошибке. Под некорректными данными стоит понимать: невалидные в контексте выбранного исчисления формула или обоснование, формула без обоснования. 
    <end>
