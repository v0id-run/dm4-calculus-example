### Сервис обработки домашних заданий

#### Назначение компонента

Данный сервис предназначен для выдачи преподавателем домашнего задания и для последующей его проверки, а также для выполнения домашнего задания студентом.

Действующие лица: преподаватель, студент.

#### Действия пользователя и реакции системы на них

* *Действие*: Преподаватель выбирает группу, которой необходимо отправить домашнее задание. Проставляет дату сдачи, прописывает требования по выполнению, прикрепляет необходимые файлы (опционально), добавляет комментарии (опционально). Нажимает кнопку "Отправить".

    *Реакция*: Если группа и дата указаны, размер файла (опционального) не слишком большой и распознаваемого формата, то сервис отправляет домашнее задание указанной учебной группе.

* *Действие*: Студент загружает файл и отправляет его на проверку.

    *Реакция*: Если размер файла не слишком большой и распознаваемого формата, сервис загружает файл на сервер, где его проверит преподаватель.

* *Действие*: Преподаватель проверяет работу и оставляет замечания в поле "Комментарий".

    *Реакция*: Сервис загружает изменения на сервер, где студент может доработать задание.

* *Действие*: Преподаватель проверяет работу и проставляет итоговую оценку в поле "Оценка".

    *Реакция*: Сервис загружает изменения на сервер, студент может увидеть свою оценку в личном кабинете.

#### Ассоциированные функциональные требования

* **Component.Homework.JobCreation**: 
    Сервис должен предоставлять преподавателю возможность создавать домашние задания.
    <end>
* **Component.Homework.FileAttachment**: 
    Сервис должен предоставлять преподавателю возможность прикладывать к созданному домашнему заданию файл.
    <end>
* **Component.Homework.JobComments**: 
    Сервис должен предоставлять преподавателю возможность оставлять комментарии к созданному домашнему заданию.
    <end>
* **Component.Homework.JobSending**: 
    Сервис должен предоставлять преподавателю возможность высылать домашние задания с указанием учебной группы.
    <end>
* **Component.Homework.CompletionDate**: 
    Сервис должен предоставлять преподавателю возможность при отправке задания указывать дату его сдачи студентом.
    <end>
* **Component.Homework.JobChecking**: 
    Сервис должен предоставлять преподавателю возможность проверить выполненное студентом задание.
    <end>
* **Component.Homework.JobRating**: 
    Сервис должен предоставлять преподавателю возможность поставить оценку за выполненное домашнее задание.
    <end>
* **Component.Homework.JobReworking**: 
    Сервис должен предоставлять преподавателю возможность оставить замечания к домашнему заданию и вернуть его на доработку студенту.
    <end>
* **Component.Homework.JobDiscussion**: 
    Сервис должен запретить возможность общения между преподавателем и студентом до возврата работы на доработку.
    <end>
* **Component.Homework.JobViewing**: 
    Сервис должен предоставить студенту возможность просматривать выданные его группе домашние задания за весь учебный семестр.
    <end>
* **Component.Homework.JobUploading**: 
    Сервис должен предоставить студенту возможность загрузить файл с выполненной домашней работой.
    <end>
* **Component.Homework.JobSubmiting**: 
    Сервис должен предоставить студенту возможность отправить домашнюю работу на проверку преподавателю.
    <end>
* **Component.Homework.JobEditing**: 
    После отправки студентом домашней работы сервис должен отобрать у студента право на ее редактирование.
    <end>
* **Component.Homework.ResultsViewing**: 
    Сервис должен предоставить возможность студенту просматривать свои оценки, проставленные преподавателем, в личном кабинете.
    <end>
* **Component.Homework.JobCorrection**: 
    В случае наличия комментариев от преподавателя, сервис должен предоставлять студенту возможность просмотра замечаний и доработки задания.
    <end>
* **Component.Homework.CommentsAddition**: 
    Сервис должен предоставлять возможность оставлять ответы к комментариям.
    <end>
* **Component.Homework.FileSize**: 
    Размер файлов, которые могут прикладывать преподаватель и студент, не должен превышать 5Мб.
    <end>
* **Component.Homework.FileFormat**: 
    Загружаемые файлы должны иметь один из следующих форматов: .pdf, .txt, .docx.
    <end>
