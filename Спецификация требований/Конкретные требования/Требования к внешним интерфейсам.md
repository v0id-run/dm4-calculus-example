## Требования к внешним интерфейсам

### Интерфейсы пользователя

* **Interface.User.Config**: 
    Сервер должен настраиваться при помощи параметров конфигурации, которые должны быть записаны в конфигурационных файлах.
    <end>

* **Interface.User.Config.Format**: 
    Конфигурационные файлы должны быть записаны в формате JSON.
    <end>

* **Interface.User.Logging**: 
    Сервер должен логгировать все запросы, предупреждения и ошибки в файл.
    <end>

* **Interface.User.Logging.Labels**: 
    Каждая запись в файл с логами должна содержать одну из меток: [INFO], [WARNING], [ERROR].
    <end>

* **Interface.User.Logging.Labels.Placing**: 
    Метка [ERROR] должна устанавливаться для записей, сообщающих об ошибках, как минимум критических для отдельной операции; метка [WARNING] должна устанавливаться для сообщений о нетипичном или потенциально приводящем к ошибке поведении системы; метка [INFO] должна устанавливаться во всех остальных случаях.
    <end>

### Аппаратные интерфейсы

* **Interface.Hardware.Processors**: 
    Сервер должен работать в условиях архитектур процессоров *AMD64* и *Intel 64*.
    <end>

* **Interface.Hardware.RAM**: 
    Сервер должен быть способным работать без сбоев при наличии 4 GB оперативной памяти и более.
    <end>

* **Interface.Hardware.Networking**: 
    Сервер должен быть способным работать без сбоев при использовании любого сетевого интерфейса, обеспечивающего минимальную стабильную скорость 1 MB/s.
    <end>

### Интерфейсы программного обеспечения

* **Interface.Software.DataCommunication**: 
    Клиентская часть должна иметь возможность обмениваться данными с серверной частью приложения. Основные типы данных: текстовые и бинарные. 
    <end>

* **Interface.Software.OS**: 
    Сервер должен быть совместимым с операционными системами Windows 7 и старше и дистрибутивами с ядром Linux версии 3.1 и старше.
    <end>

* **Interface.Software.OS.Signals**: 
    Сервер должен прерывать работу при получении сигнала "SIGINT".
    <end>

* **Interface.Software.OS.Files**: 
    Сервер должен иметь возможность создавать, удалять, модифицировать и читать файлы.
    <end>

* **Interface.Software.OS.Networking**: 
    Сервер должен иметь возможность взаимодействовать с внешней сетью по протоколу TCP/IP.
    <end>

* **Interface.Software.DataBase**: 
    Сервер должен иметь возможность устанавливать соединение с СУБД MySQL и взаимодействовать с ней посредством SQL запросов.
    <end>

### Интерфейсы связи

* **Interface.Connection.DataCommunicationProtocol**: 
    Обмен любыми данными между клиентом и сервером должен происходить по протоколу HTTP/1.1 [1].
    <end>

* **Interface.Connection.AuthenticationDataFormat**: 
    Аутентификационные данные должны передаваться между клиентом и сервером в формате JSON Web Token [2]. 
    <end>

* **Interface.Connection.TextDataFormat**: 
    Текстовые данные, которыми обмениваются клиент и сервер, должны быть в формате JSON [3]. 
    <end>
