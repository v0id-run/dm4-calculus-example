## Ограничения

* **Limitation.Server.ProgrammingLanguage**:
    Реализовать серверную часть системы на языке программирования Go (Версия: 1.13.1).
    <end>

* **Limitation.Server.ListenerType**:
    Использовать протокол HTTP/1.1 [2] для приёма запросов и отправки ответов сервером системы.
    <end>

* **Limitation.Client.ProgrammingLanguage**:
    Реализовать клиентскую часть системы на языке программирования JavaScript с применением фреймворка Vue.js.
    <end>

* **Limitation.UnsupportedBrowsers**:
    Реализация системы может не гарантировать полную поддержку браузеров без официальной поддержки или обновлений в течение 24 месяцев (IE 10, IE_Mob 10, BlackBerry 10, BlackBerry 7, Samsung 4 и OperaMobile 12.1), а также Opera Mini всех версий.
    <end>

* **Limitation.Markdown.SupportGFM**:
    Обеспечить поддержку синтаксиса Github Flavored Markdown.
    <end>

* **Limitation.Markdown.SupportLatex**:
    Обеспечить поддержку ввода математических формул на языке Latex. В качестве библиотеки для реализации на клиенте системы использовать katex.js.
    <end>
