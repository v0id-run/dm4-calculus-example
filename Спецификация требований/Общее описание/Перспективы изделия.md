## Перспективы изделия

Лабораторный комплекс по курсу "Дискретная математика (логические исчисления)" представляет из себя автономное веб-приложение, позволяющее сделать учебный курс более удобным для преподавателей и студентов. 

Ниже приведена схема архитектуры системы.

![Трёхуровневая архитектура системы](../../images/general_system_architecture.jpg)

Лабораторный комплекс представляет из себя трехуровневое клиент-серверное приложение, состоящее из базы данных, сервера и клиентской части.

В свою очередь серверная часть состоит из четырех компонентов: 

* Сервис обработки домашнего задания
* Сервис поддержки вывода формулы
* Сервис проверки истинности формулы
* Сервис авторизации

Также есть возможность добавления новых сервисов в лабораторный комплекс, что позволит в будущем расширить его функциональность.
