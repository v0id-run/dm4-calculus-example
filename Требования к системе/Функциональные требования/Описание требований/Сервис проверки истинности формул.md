### Сервис проверки истинности формул

#### Описание

Сервис предназначен для проверки истинности формул одного из логических исчислений. Доступен для всех типов пользователей.

#### Функциональность

**Пользовательские требования**

Необходимо предоставить всем пользователям возможность:

1. выбора логического исчисления; 
2. ввода логической формулы на языке Logical Formulas;
3. просмотра введенной формулы, отображенной в Latex; 
4. проверки введенной формулы на истинность.

**Функциональные требования**

Система должна:

1. рендерить введенную пользователем на языке Logical Formulas формулу в Latex;
2. проверять введенную пользователем формулу при помощи главной интерпретации исчисления:
    * для $P_1$, $P_2$ - обычная матлогика;
    * для $F_1$, $F_2$ - метод резолюций;
    * для $P_I$​ -  трёхзначная псеводобулева алгебра;
    * для модального исчисления - некоторая модель Крипке;
3. выводить на экран результат в виде текстовой строки со значениями *Истинна* и *Не истинна*.


**Элементы**

На странице сервиса должны присутствовать описанные ниже элементы:

1. выпадающий список, который позволит выбрать одно из следующих логических исчислений:
    * пропозициональное $P_1$;
    * пропозициональное $P_2$;
    * секвенций $LK$;
    * функциональное $F_1$;
    * функциональное $F_2$;
    * интуиционистское пропозициональное $P_I$;
    * модальное пропозициональное;
2. поле ввода формулы;
3. нередактируемое поле с отображением формулы в Latex;
4. нередактируемое поле с результатом проверки формулы.

**Валидация**

Если в поле ввода формулы записано выражение, которое невозможно корректно обработать, то выводить на экран уведомление об ошибке.
