# Среда разработки

1. Для написания документации требований используется язык Markdown, а в качестве текстового редактора выбран Visual Studio Code с расширением Markdown Preview Enhanced от Yiyi Wang.
2. Проектирование осуществляется при помощи CASE-средств с визуализацией в draw.io, aris express и microsoft visio.
3. Среда разработки для web-интерфейса - WebStorm, для сервера - GoLand и vscode с go-расширением. Для проектирования базы данных используется MySQL Workbench и mysql TUI.
