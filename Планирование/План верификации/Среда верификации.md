# Среда верификации

## Инструменты тестирования

В таблице, приведенной ниже, описываются используемые инструменты для тестирования:

| Название инструмента  | Предназначение инструмента |
| -------------         | -------------              |
|Gitlab        | Проведение форммальной инспекции для тестирования требований, хранение тестовой документации               |
| Пакет *testing*        | Пакет для модульного тестирования кода серверной части              |
| Пакет *testify*  | Пакет с дополнительными инструментами тестирования кода серверной части                           |
| Gitlab CI                 | Система непрерывной интеграции                               |
| Charles                      | Инструмент для перехвата трафика веб-приложения                           |

## Порядок применения инструментов

### Тестирование документации

Для начала необходимо протестировать документацию, что осуществляется при помощи формальной инспеции в gitlab.

### Автоматизированное тестирование

После написания кода происходит покрытие тестами (а также запуск этих тестов) при помощи функционала пакетов testing и testify. Затем при помощи CI сборка запускается по нужному алгоритму, что помогает избежать проблем с интеграцией.

### Ручное тестирование

Интерфейс тестируется при помощи предварительно составленной тестовой документации, хранящейся в репозитории gitlab. Кроме того, при помощи Charles проверяется валидность данных, которые приходят с сервера, а также производится подмена данных для проверки корректности отображе6ния изменений на интерфейсе.
