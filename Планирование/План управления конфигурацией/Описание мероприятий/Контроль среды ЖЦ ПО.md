## Контроль среды ЖЦ  
 Актуальные версии единиц конфигурации расположены основной ветке проекта ( ветке **master** ).

Доступ к инструментам:

* компилятор Golang с официального сайта (https://golang.org/dl/)
* платформа JetBrains GoLand с официального сайта (https://www.jetbrains.com/go/)
* платформа Node.js с официального сайта (https://nodejs.org/en/download/)
* редактор Visual Studio Code с официального сайта (https://code.visualstudio.com/download)
* расширения Markdown Preview Enhanced, Code Spell Checker, Go из каталога расширений Visual Studio Code
* пакетный менеджер Npm загружается автоматически с Node.js
* среда разработки WebStorm для JavaScript с официального сайта (https://jetbrains.ru/products/webstorm/)
* средство построения диаграмм https://www.draw.io/
